# vpn-site

Сайт VPN-сервиса CRS. Общий контекст и решения: `/Users/will/Documents/CRS-Projects/Servers/docs/САЙТ_2026-09-23/`.

- Репозиторий ПУБЛИЧНЫЙ. Никаких секретов, `.env`, дампов, IP-адресов нод и токенов в коммитах.
- Мобильная и десктопная версии обязательны. Каждый экран проверять на 390px и 1280px.
- Дизайн: принципы Teenage Engineering (`docs/design-principles.md`). Один акцент `#f05a24`, никакого желтого.
- Данные бота только через слой `bot-gateway` (сейчас заглушки, после релиза бота 3.0 API бота). Вебхук ЮKassa один, на боте.
- Входы: Telegram, email + пароль, паскей. Админка на отдельном поддомене, паскей + TOTP.
- Сервер и изоляция: `deploy/README.md`. Не трогать чужие контейнеры на app-сервере.
