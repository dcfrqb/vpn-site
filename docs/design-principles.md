# Дизайн сайта: принципы Teenage Engineering

Разбор teenage.engineering 23.09.2026: главная, OP-1 field, EP-133 K.O. II, магазин. Токены сняты из их CSS.

## Что у них на самом деле

**Цвет.** Почти монохром. Фон `#fff` / `#f5f5f5` (te-white), текст `#0f0e12` (te-black), шкала серых `#e5e5e5 → #272727`.
Акценты выдаются по одному, как цветная клавиша на корпусе: оранжевый `#f05a24`, желтый `#fab413`, синий `#0071bb`, зеленый `#006837`, красный `#b81d13`.
На странице продукта обычно ровно один акцент (EP-133: оранжевый; OP-1: оранжевый + желтый баннер кук).

**Шрифт.** Свой гротеск `te-20` / `te-40`, веса 100–300. Все тонкое, нижний регистр, никакого bold в UI.
Крупные заголовки (DAILY LIFE, K.O. II) идут другим, геометричным шрифтом, иногда контуром. Японские подписи как декоративный слой.
Спецификации: моно-подобный набор, КАПСОМ, списком без маркеров (список «100 новых фич» у OP-1).

**Сетка.** Все размеры считаются от ширины экрана (`--client-width`, базовая ширина 980): отступы, кегли, радиусы. Сайт масштабируется как чертеж, а не перестраивается.
Разделители тонкие, 1px `#b2b2b2`. Скругления у плиток ~2.5% ширины.

**Навигация.** Шапка из 5 разделов: у каждого пиктограмма-глиф (цветок, коробка, квадрат, лупа с диском), крупное слово и 3 мелкие подссылки под ним. Меню сразу раскрыто, ничего не прячется в гамбургер.

**Продукт как интерфейс.** Устройство рисуется плоской векторной схемой (EP-133 из квадратиков-кнопок) или снимается на ровном сером фоне. Экран OP-1 с его пиксельной графикой (кассета, волна, меню) используется прямо в макете как иллюстрация.

**Тон.** Короткие строки, нижний регистр, самоирония («if it feels thinner. it is.», «the back is warm, velcro and bass»). Факты вместо эпитетов: «128 MB sampler», «100 times better».

**Куки-баннер.** Желтый треугольник-предупреждение с ладонью «стоп». Кнопки settings / accept all, внутри настроек required / analytics / advertising и отдельная decline. Юридически полный и при этом фирменный.

## Как перенести на VPN-сайт

Не копировать их сайт, а взять принцип «продукт = прибор».

1. **VPN как железка.** Главный визуал: плоская схема «прибора» (корпус, кнопки = локации, индикаторы = ноды, мини-дисплей со статусом). Подписка выглядит как устройство, которое «включаешь».
2. **Дисплей OP-1 → личный кабинет.** Черная плашка-экран с пиксельной/моно графикой: остаток дней, трафик полосой-VU-метром, пинг до нод. Остальная страница светлая.
3. **Палитра.** Белый/серый + te-black. Один фирменный акцент (предлагаю оранжевый `#f05a24` как «включено»), желтый только для предупреждений (куки, конец подписки), зеленый/красный только для статусов нод.
4. **Шрифты.** Тонкий гротеск нижним регистром для текста (кандидаты с кириллицей: Inter Tight 200–300, Manrope 200, Golos UI), моно для цифр и спецификаций (JetBrains Mono / IBM Plex Mono). Проверить кириллицу до выбора.
5. **Космос/инженерия.** Лаконично: координатные метки, серийные номера («CRS–01», «node nl–1 / AS56971»), техплашки, тонкие линейки. Без звездного неба и градиентов.
6. **Тарифы как спецификация.** Каждый тариф карточкой на сером фоне с таблицей характеристик капсом: локации, устройства, трафик, протокол.
7. **Куки-баннер** своим «приборным» знаком, со всеми юридическими опциями (см. раздел про юриста).
8. **Масштаб от ширины** (clamp + vw), разделители 1px, пиктограммы-глифы в навигации.

## Не брать

- Фото знаменитостей и чужие иллюстрации (права).
- Их шрифты te-20/te-40 и логотип: проприетарные.
- Перегруз анимацией: у TE ее мало, это и держит ощущение «инструмента».
